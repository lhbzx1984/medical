# 写实人体与解剖层-20261031：证据说明

日期：2026-10-31（本机时钟 21 时至 23 时前后）。对应 `mackdown.md` 第 6.2、7.7 节。本文件夹只放这一轮的证据，起点是队友更新后的 `main`（`3a1b1e0`）；之前的证据文件夹没有被改动或覆盖。

## 1. 这一轮做了什么

目标：让 3D 人体与器官更接近真实，同时保留原有功能。精细人体图谱（2,234 个结构、15 个系统）照常可以查看骨骼、血管等，3D 同屏另外新增骨骼 / 动脉 / 静脉三个图层。没有找到单独的“修订说明”文件；所依据的现状描述是队友的 `剩余器官3D修正-20261031/说明.md` 第 6—8 节、`mackdown.md` 第 8 节待办、`CLAUDE_HANDOFF.md` 与 README 的 HuBMAP 章节。

- **体表**：男性换成 BodyParts3D 皮肤（含头发、眉毛、嘴唇，与器官在同一图谱坐标系里）；女性仍是 HuBMAP 参考网格，只升级了材质。
- **光照与材质**：`StudioLighting`（程序化环境光 + 三点灯光）取代三处各自写的灯光；`realistic-materials.ts` 给皮肤（次表面近似、微法线、透视模式的菲涅尔透明）、毛发、嘴唇、骨骼、血管和各器官（清漆湿润高光）设置材质。
- **解剖层**：骨骼、动脉、静脉三层，打开某一层时才下载对应 GLB，体表自动让开。
- **双眼**：右眼复用左眼模型并沿身体中线镜像（此前只有一个眼球，近看时右侧眼眶会透出后面的脑）。
- **脑与眼球的取值**回到图谱坐标：体表现在就是图谱皮肤，不再需要此前为旧人形轮廓加的 0.06 抬升。
- **删除**：`learn/ReferenceBody.tsx`（已移到 `sim/`，学习中心与手术规划共用）和 `public/models/hra-skin-male.glb`（19.9 MB，不再被任何代码或测试引用，相同内容在 `3a1b1e0` 的历史里）。

没有改动：`AtlasViewer`、`BodyOutline`（仍是加载期间的占位轮廓）、`FemaleReproductive`、全部器官 GLB、其余 8 个器官的位置与大小、AI 导师、学习自测、手术规划的 API 与存储、`package.json` 与依赖、`supabase`；没有创建或修改 `.env.local`。差异见 `本次改动.patch`（`src`、`tests`、`scripts` 共 16 个文件，+852 / −145 行），逐项说明见 `mackdown.md` 第 6.2 节。

## 3. 方法与注意事项

1. **基线在改动之前运行。** 先把项目目录同步到队友最新的 `3a1b1e0`（项目目录没有 `.git`，用临时目录里的克隆逐文件比较），再在这一版上运行同一套检查：构建、类型检查、ESLint 退出码 0，`npm test` 102/102，合成完整链路 19/19（`修改前/`）。
2. **改动后的检查**（`修改后/`）每一步一份日志，退出码另存为 `.exit`。类型检查在构建之后运行，因为 `.next/types` 在检查范围内。ESLint 与类型检查没有输出（0 错误、0 警告）。`npm test` 107/107，其中 12 个是在 PGlite 里执行 `supabase/schema.sql` 的 SQL 测试。
3. **最终树检查**（`修改后/最终树检查/`）：上述检查之后又删除了 `hra-skin-male.glb`（先确认它与 `3a1b1e0` 里的 blob 逐字节相同、代码与测试里没有引用）并更新了文档，所以在最终文件树上把构建、类型检查、ESLint、`npm test`、合成完整链路重新跑了一遍，写进新文件夹，没有覆盖上一轮。结果相同：退出码都是 0，107/107，19/19。这之后只改了文档并加入本证据副本，代码、测试与模型文件没有再变。

## 4. 仍然存在的问题（详见 `mackdown.md` 第 6.2、8 节）

- 女性体表仍是没有面部的 HuBMAP 参考网格，只升级了材质，写实程度明显不如男性；要同等水平需要新的女性网格，下载素材须先经批准。
- 女性模式的骨骼与血管取自男性图谱，位置、姿势与女性体表不一致，仅作示意。
- 体表与图层合计约 47 万三角形，低端 GPU 与手机上的帧率没有验证。
- 右眼与左眼是同一个模型，视神经残端没有镜像（藏在头里，只有透视模式下可能看到）。
- 骨骼 / 动脉 / 静脉开关只在学习中心的 3D 同屏里，手术规划页没有。
- 写实程度是目视判断：男性面部仍是图谱的平滑网格，不是照片级；没有对照真实照片，也没有第三方评审。体表与器官是示意配准，不声明医学准确性。

## 5. 复现

在项目目录：

```bash
npm run build
node node_modules/typescript/bin/tsc --noEmit --incremental false
npx eslint .
npm test
```

合成完整链路：构建之后，终端一 `node tests/e2e-server.cjs`，终端二 `node tests/e2e-flow.cjs`，两边设置同一个**新的** `MEDPLAN_TEST_OUTPUT`（该目录须已存在）。体表与图层 GLB 由 `node scripts/extract-body-layers-glb.mjs .` 从 `public/atlas` 重新生成。
